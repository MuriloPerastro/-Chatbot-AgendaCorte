# -Chatbot-AgendaCorte
A ideia do projeto é a criação de um chatbot inteligente para barbearias e salões de beleza que atende os clientes de forma automatizada para facilitar o agendamento de horários, escolha de profissionais, consulta de serviços (corte, barba, química) e envio de lembretes, desafogando a recepção e eliminando falhas de marcação.
